# التقويم ومسار الطالب والمتابعة

- **التقويم الموحّد:** في بوابات الطالب والمدرب وإدارة الأكاديمية (المالك والمدير). يعرض المحاضرات وبداية الاختبارات ومواعيد التسليم، مع فلترة حسب الدورة والنوع، وتوقيت الأكاديمية، وقائمة مواعيد خلال 24 ساعة من وقت التحديث. يعرض للطالب جلسات مجموعته والجلسات العامة لدورته فقط.
- **تذكير الجهاز:** زر «إضافة إلى تقويم الجهاز» يصدر ملف ICS للمواعيد المعروضة حسب الفلتر، بما فيها أيام الشهر المجاورة في الشبكة. المواعيد المستقبلية غير المغلقة تتضمن تنبيهًا قبل 30 دقيقة. يحتاج المستخدم إلى استيراد الملف وتفعيل التنبيهات في تطبيق تقويمه. الملف نسخة ثابتة؛ تغييرات المواعيد تحتاج تصديرًا جديدًا. ليست هذه رسائل بريد أو WhatsApp ولا إشعارات دفع في الخلفية.
- **مساري الدراسي:** في بوابة الطالب. يحسب الدروس المنشورة المكتملة والمتبقية، ويفتح الدرس التالي مباشرة، ويعرض مسار الدروس والتسليمات والمحاولات المنتهية. إتمام محاولة اختبار لا يعني اجتيازه. لا تدخل الواجبات ذات الموعد السابق لتسجيل الطالب في عداد مهامه. الدروس بلا محتوى منشور لا تظهر مكتملة تلقائيًا.
- **متابعة الطلاب:** للمالك والمدير، وللمدرب ضمن دوراته ومجموعاته. إشارات للمراجعة بناءً على يومي غياب مسجلين أو واجبين متأخرين دون تسليم في آخر 30 يومًا وبعد التسجيل. يجمع السببين تحت «أولوية متابعة». المصدر هو سجل الحضور اليدوي فقط، وليس غياب سجل الدخول أو Zoom. لا يغيّر درجات أو صلاحيات أو حالة الطالب ولا يرسل رسائل تلقائية. التسجيلات المتوقفة أو الملغاة أو المكتملة لا تُحسب، والسجلات غير الموجودة لا تُفترض غيابًا.
- المتابعة تقرأ حتى 50 تسجيلًا في الصفحة؛ أعداد التنبيهات تخص الصفحة الظاهرة، وتوجد أزرار لباقي التسجيلات. مراجعة الحضور والواجبات تفتح الصفحات الحالية. تختفي المؤشرات عند تصحيح الحضور أو وصول التسليم في القراءة التالية.

## التحقق

شغّل `npm run test:learning` لاختبارات API في قاعدة مؤقتة معزولة، و`npm run test:syntax` لفحص JavaScript ومراجع الأصول. تشمل الاختبارات عزل الأكاديميات ومجموعات المدربين، الحالات غير النشطة، الدروس غير المنشورة، انتهاء المواعيد، وتصحيح التنبيهات وتصدير ICS.

لا توجد ترحيلات قاعدة بيانات أو مفاتيح خدمة جديدة لهذه الإضافات. المعاينة البصرية في متصفح فعلي تحتاج اختبارًا مستقلًا، خصوصًا الجوال وتطبيق التقويم الذي سيستورد الملف.
